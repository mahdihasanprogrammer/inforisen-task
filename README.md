## 📌 Project Overview

This project delivers a responsive, accessible, and visually stunning landing page tailored for Bangladeshi businesses, agencies, and content creators. It highlights social proof, reliable delivery guarantees, regional payment gateway integrations (bKash, Nagad, Rocket), and comprehensive social media marketing packages.

---

## ✨ Main Features

- **Navigation Header:** Clean, responsive navbar with logo, smooth link anchors, and mobile drawer menu.
- **Hero Section:** High-converting hero area featuring a Trustpilot-style rating badge, bold typography, CTA buttons, and graphic artwork.
- **Statistics Counter:** Highlights completed orders, active services, registered users, and regional rankings.
- **Interactive Services Showcase:** 12-platform tabbed switcher (Facebook, Instagram, YouTube, TikTok, LinkedIn, Spotify, etc.) displaying specific features and benefits with animated transitions.
- **4-Step Working Process:** Step-by-step visual roadmap with central orbit node and custom card borders.
- **Supported Payment Methods:** Graphic visualization of regional and global payment methods (bKash, Nagad, Rocket, Visa, Mastercard, Crypto).
- **Growth Timeline:** 4-stage timeline breakdown detailing what to do, why it works, and estimated investment for social media growth.
- **Advantages Section:** Clear highlight cards detailing security (no passwords requested), bot-free delivery, gradual drip-feed, and track record.
- **Interactive FAQ:** Two-column accordion answering common customer inquiries with smooth expand/collapse transitions.
- **CTA Banner:** Eye-catching conversion card with subtle world map watermark and specialist graphic.
- **Footer:** Brand summary, social media links, quick navigation, service pages, and contact details with centered container constraints.
- **Tasteful Animations:** GPU-accelerated scroll reveals, card hover effects, and button micro-interactions powered by Framer Motion.

## ⚙️ Getting Started

### Prerequisites

Ensure you have the following installed on your machine:
- **Node.js**: v18.18.0 or newer (v20+ recommended)
- **npm**, **yarn**, or **pnpm**

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/inforisen-task.git
   cd inforisen-task
   ```

2. Install project dependencies:
   ```bash
   npm install
   ```

### Running Locally

Start the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

---

## 🏗️ Building for Production

Create an optimized static and server build:
```bash
npm run build
```

To run the production build locally:
```bash
npm run start
```
